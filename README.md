Phillies Hitting Analysis (2025)

This project analyzes the Philadelphia Phillies' 2025 offense using FanGraphs team batting statistics.

Research Question

Which Phillies hitters created the most offensive value, and was that value driven more by power, plate discipline, or all-around production?

Key Takeaways
Kyle Schwarber led the Phillies in power production metrics including ISO and OPS.
Trea Turner provided strong all-around value through offense, speed, and WAR.
Bryce Harper remained one of the Phillies' top overall offensive contributors.
ISO and OPS helped visualize how power impacted offensive production.
